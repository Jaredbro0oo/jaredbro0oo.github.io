## Cómo publicar con GitHub Pages

1. Sube estos archivos a un repositorio. Si lo llamas `TU-USUARIO.github.io`, el portafolio queda en la raíz de tu dominio.
2. Entra a **Settings → Pages**.
3. En **Branch** elige `main` y la carpeta `/ (root)`. Luego presiona **Save**.
4. En uno o dos minutos el portafolio queda en `https://TU-USUARIO.github.io/`.

Para editar los textos o agregar proyectos, cambia `build.py` y ejecuta `python3 build.py`. Eso vuelve a generar `index.html`.
